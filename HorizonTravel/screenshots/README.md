# App Screenshots & Demo Walkthrough

This directory contains demo captures of the Horizon Travel Android app across different flows.

### Guest & Public Landing Experience
- [`screen.png`](screen.png) — Default public landing screen with hero banner and "Services Provided by Horizon" feature cards.
- [`screen2.png`](screen2.png) — Live Provider Services section with search bar, horizontal category filter chips, and real-time database slots.
- [`screen_buses.png`](screen_buses.png) / [`screen3.png`](screen3.png) — Category filter demonstration (filtered by "Buses").
- [`screen_search.png`](screen_search.png) — Real-time keyword search demonstration (e.g., searching "Dhaka").
- [`screen_detail.png`](screen_detail.png) — Service Slot detail screen showing provider information, route, dates, and ratings.
- [`screen_prompt.png`](screen_prompt.png) — **"Sign In Required"** dialog prompted when a guest attempts to book or add a service to cart.
- [`screen_login_clean.png`](screen_login_clean.png) — Clean sign-in screen with top back button and "Explore Services as Guest" link (debug settings icon removed).

### Role Shells & Authenticated Portals
